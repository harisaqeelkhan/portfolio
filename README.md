# Muhammad Haris Khan Portfolio

Welcome to my portfolio repository. This collection brings together projects and case studies across blockchain development, financial analysis, business intelligence, database design, leadership, and quantitative research. Each folder highlights a different skill set, but the common thread is the same: building practical, well-structured work with attention to detail and real-world use cases.

## About This Portfolio

This repository is organized as a curated set of project folders rather than a single application. It is intended to give a clear view of my technical range, analytical thinking, and ability to work across tools and domains.

A decentralized marketplace concept built on Ethereum and Web3 technologies. The project focuses on smart contract-based commerce, escrow-style transaction flow, and a modern frontend experience for buyers and sellers.

### Financial Models
Financial analysis work focused on valuation, forecasting, and decision support. This section reflects structured modeling, quantitative thinking, and business interpretation.

### Leadership - Snow Leopard Foundation
Leadership and community impact work that highlights initiative, responsibility, and organizational contribution beyond technical delivery.

### Power BI Dashboards
Interactive dashboard work designed to turn data into clear business insights through reporting, visualization, and executive-friendly presentation.

### SQL Financial Database
A database-oriented project centered on financial data management, SQL querying, and structured data design. This section includes the database file and supporting SQL code.

### US Monetary Circulation Model (Stata)
A research-driven analytics project built in Stata, with supporting datasets, graphs, and written analysis for monetary circulation modeling.
